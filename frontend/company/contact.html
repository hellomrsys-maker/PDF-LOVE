Before you write in

Two things come up often enough to answer here:

  • "Where did my file go?" Nowhere. On-device tools write the result straight to your downloads folder. Check there first.
  • "Can you recover a PDF password I've forgotten?" No. Dockbench can remove a password you already know; it cannot break encryption you've lost the key to, and we wouldn't build that.

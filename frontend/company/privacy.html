The short version

PDF Love processes your files entirely on your own device. For the vast majority of tools nothing about your files — not their contents, not their names, not even the fact that you used a tool — is ever sent anywhere. There is no account system for individuals, so there is no login, no email address and no personal profile for us to collect in the first place.

What we do not collect

  • File contents or filenames processed by on-device tools — merge, split, compress, OCR, encrypt, redact, and the rest of the 94 on-device tools
  • Analytics, trackers or advertising identifiers, by default
  • Any account information for individual users — there is no login
  • Location data, contacts or device identifiers

What optional features collect, only if you use them

  • Server-assisted tools (Office→PDF full fidelity, deep compression, PDF/A, background removal, chat-with-PDF): these appear only when a backend is available, and send only the file you explicitly submit to that specific tool — to a backend operated by us or self-hosted by you. That backend logs no file contents or filenames, and deletes per-request temporary files immediately after the response is built.
  • Currency converter: fetches live exchange rates from a third-party provider. No file or personal data is sent, though the request itself reveals your IP address to that provider, as any network request would.
  • On-device AI features (background removal, summarize, translate, voice-to-text, image captioning): the models download once from their public host and are cached in your browser. After that first download these run fully offline.
  • Advertising, if enabled by whoever operates this deployment: off by default. If an operator turns it on, that ad network's own privacy policy governs ad delivery. Note that we add no tracking of our own alongside it — there is no PDF Love analytics, no telemetry, and no platform-detection ping. An ad network already sees your platform, browser and IP when it serves an ad, so there is nothing for us to add.

Business API customers

If you hold an API key we necessarily store the account details you gave us — billing contact, company name — and a count of requests made against your key, so we can invoice you and enforce limits. We do not log the contents or names of files submitted through the API.

Self-hosted and enterprise deployments

If you use a self-hosted or enterprise deployment with its own login or SSO, that operator's privacy policy governs your account and any audit logs they keep. This document describes the public product only.

Your rights

The API

A REST API over the server-side engines: OCR to searchable PDF, full-fidelity Office conversion via LibreOffice, deep compression and PDF/A archival via Ghostscript, and background removal. Authentication is a bearer API key. Interactive documentation is served at /docs on any running instance.

The API is the paid surface. The on-device app stays free and unlimited for everyone, with no key — that isn't a trial we plan to close.

Air-gapped and offline deployments

For environments with no internet at all — secure facilities, some libraries and schools, field equipment — Dockbench runs from a signed licence key that is verified entirely on-device using the Web Crypto API. No activation call, no phone-home, no licence server, ever. One key can cover every machine at a site.

Self-hosting

The backend is open-source and ships as a Docker image. docker compose up -d gives you the API, a job queue and a worker pool you can scale independently. Your documents never leave your infrastructure, which is usually the entire reason procurement is involved in the first place.

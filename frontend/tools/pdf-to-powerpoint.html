Convert PDF to PowerPoint

Turn a Portable Document Format into a Microsoft PowerPoint deck (.pptx) without sending it anywhere. The conversion runs on your own device.

Your file never leaves this device. Pick a file and watch the Network tab — nothing fires while it is being processed. No upload, no account, no daily limit.

How to convert PDF to PowerPoint

  1. Open the PDF to PowerPoint tool.
  2. Choose your PDF file, or drag it onto the page.
  3. Adjust the options if you want to — defaults are sensible.
  4. Download the PowerPoint result. It saves straight to your downloads folder.

What survives the conversion

This is one of the ten server-assisted tools, and the only ones on this site that transmit your file: it needs a rendering engine far too large to ship into a browser. It appears only when a backend is configured, is labelled server-assisted in the interface, and that backend can be one you run yourself. Recovered text becomes editable text boxes; complex graphics arrive as positioned images.

Common questions

Is my file uploaded for this?

Yes. Unlike the on-device tools, this one sends the file to the configured backend — which may be your own.

Will the slides be fully editable?

Text that can be recovered becomes editable. Graphics come across as images.

Page Numbering & Document ID

Two different needs share one tool: page numbers for a document that will be printed or cited, and a fixed reference stamped on every page — a case number, a GST number, a Bates number for discovery.

Your file never leaves this device. Pick a file and watch the Network tab — nothing fires while it is being processed. No upload, no account, no daily limit.

How to use Page Numbering & Document ID

  1. Choose the PDF.
  2. Pick auto-counting numbers, or a fixed text that repeats on every page.
  3. Set the position, the starting number, and any prefix.
  4. Click Apply & download.

What to know

Bates numbering — a continuous sequence across a bundle, often with a prefix like ABC-000123 — is the standard in legal discovery, and the starting number matters because bundles continue from one another. Numbers are drawn into the page as real text, so they survive printing, copying and further conversion, and can be searched for later.

Common questions

Can I start at a number other than 1?

Yes. Set the starting number — necessary when this bundle continues from a previous one.

Can I skip the cover page?

Set the start so the first numbered page is the one you want, or split the cover off, number the rest, and merge them back.

Will the numbers survive printing?

Yes. They are written into the page content, not added as an annotation layer.

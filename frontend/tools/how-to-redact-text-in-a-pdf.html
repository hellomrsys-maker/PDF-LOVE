How do I properly redact text in a PDF?

Removes the text, rather than drawing a black box over text that is still there.

Your file never leaves this device. Pick a file and watch the Network tab — nothing fires while it is being processed. No upload, no account, no daily limit.

The short answer

Removes the text, rather than drawing a black box over text that is still there.

What is actually going on

This is the mistake that has embarrassed governments and law firms repeatedly: a black rectangle drawn over a name is an annotation sitting above the text, and the text is still in the file underneath. Select the page, paste it into a text editor, and the redacted names come straight out. Proper redaction deletes the characters from the content stream and then draws the box, so there is nothing left to recover. Two things to check afterwards. Metadata and attachments are separate from page content, and a document title or embedded file can leak what you just removed. And on a scanned page there is no text to delete, so the black box must cover the image itself.

Step by step

  1. Open Search & Redact and load the document.
  2. Search for the term, or select the passages by hand.
  3. Apply the redaction so the text is removed, not covered.
  4. Reopen, select all, and paste elsewhere to confirm nothing survives.

Common questions

Is drawing a black box in a PDF editor good enough?

No. That is the single most common redaction failure — the text stays in the file and can be copied straight out.

Does it clean the metadata too?

Check it separately. Document properties and attachments are stored outside the page content.

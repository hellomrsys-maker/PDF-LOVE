Favicon Generator

A favicon is not one image. Browsers, phones and bookmark bars each want different sizes, and the tab icon that looks fine at 64 pixels is often unreadable at 16.

Your file never leaves this device. Pick a file and watch the Network tab — nothing fires while it is being processed. No upload, no account, no daily limit.

How to use Favicon Generator

  1. Choose a square logo or image, ideally 512×512 or larger.
  2. Every required size is generated, including a multi-resolution .ico.
  3. Copy the HTML tags provided.
  4. Download the .zip and drop the files into your site root.

What to know

The set covers the classic 16 and 32 pixel favicons, the 180-pixel Apple touch icon, and the Android icons a web app manifest expects, plus a legacy .ico containing several sizes in one file. Detailed logos rarely survive the smallest sizes — a simple mark or a single letter reads far better in a tab than a shrunken wordmark, which is worth knowing before you generate anything.

Common questions

What source image should I start from?

Square, 512×512 or larger. Simple marks work far better than detailed logos at small sizes.

Do I still need an .ico file?

It is included for older browsers. Modern ones use the PNGs.

Where do the files go?

Your site root, with the supplied HTML tags in the page head.

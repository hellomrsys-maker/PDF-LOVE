Using Put Multiple Pages on One Sheet

  1. Open the tool.
  2. Choose your file, or drag it onto the page.

What happens to your file

Nothing leaves this device. The file is read with the browser's File API, processed in page memory, and handed back through the browser's own download mechanism. There is no request to send, because there is nothing to send.

Common questions

Yes — no account, no daily limit, no card.

Does it work offline?

Yes. After the first visit the app is cached, so it keeps working with no connection.

Are my files uploaded?

No. Everything happens in your browser, on your own device.

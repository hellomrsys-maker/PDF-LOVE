How to black out private info in a PDF

Drawing a black box over text in a PDF viewer often doesn't actually remove the text underneath — it's still there if someone selects or copies it. Real redaction removes the underlying text entirely, not just hides it visually.

Why the black rectangle does not work

This is the mistake that has embarrassed law firms, government departments and newspapers, repeatedly and publicly. A PDF is built in layers. The page content — the characters, their positions, the images — is one thing. Annotations drawn on top, including that black rectangle, are another. Drawing a box changes what is displayed; it does not remove what is stored. The name is still in the file, sitting underneath the rectangle in full.

Recovering it takes no skill at all. Select the region and copy: the text comes out. Run any text extraction tool and the redacted passages appear in the output. Some readers will even let you drag the annotation aside. If the document has been filed, published or emailed, everyone who has a copy has the original information, and there is nothing you can do about it afterwards.

What real redaction does instead

Proper redaction deletes the characters from the page's content stream — they stop existing in the file — and then draws the covering box so the page still reads as deliberately redacted rather than mysteriously blank. The order matters: remove first, cover second. Because the text is genuinely gone, there is nothing left to select, copy, extract or recover, and the file is safe to hand to someone whose interests differ from yours.

Finding everything that needs to go

Manual selection misses things — that is the normal failure, not an unusual one. A national insurance number appears in the header of page one and again in a table on page fourteen. An email address is in the body and also in a signature block. Searching for a pattern catches every instance, which is why pattern search over hand-marking is the right default for identifiers with a known shape: account numbers, phone numbers, email addresses, dates of birth.

Then read the document again for the things a pattern cannot find. Names, addresses and job titles have no fixed format. Neither does the detail that identifies someone by combination rather than directly — "the only left-handed surveyor in the district office" needs no name attached.

The three places redaction leaks

  • Metadata. Document properties carry an author, a title and often the original filename. Redacting the body of Smith-termination-draft.pdf while the title field still says so accomplishes nothing.
  • Attachments and layers. A PDF can carry embedded files and optional content groups that are not visible on the page you are looking at but travel with the document.
  • Scanned pages. There is no text to delete on a scan — the information is in the pixels. The covering box has to be applied to the image itself. And if the scan has been through OCR, there is also a hidden text layer holding a transcript of exactly what you are trying to remove, which must go too.

Verifying before you send

Do not trust the appearance. Open the finished file, select the entire document, copy, and paste into a plain text editor. Then read what comes out. If a redacted name appears anywhere in that paste, the redaction failed and you have found it in the only way that reliably works. Search the extracted text for each removed term specifically as well — it takes a minute and it is the difference between a redaction and a mistake.

Worth knowing: for genuinely sensitive material, some organisations still print, black out with a marker, and rescan. That works because it destroys the information physically. Real digital redaction achieves the same result without the loss of quality — provided you verify it, which is the step people skip.

This is exactly the kind of task where uploading to a cloud service is the wrong move — the whole point of redaction is removing sensitive information, not sending it to a third party first. PDF Love redacts locally, so the sensitive data only ever exists on your own device.
